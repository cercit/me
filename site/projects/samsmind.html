SamsMind brings capture, filing, search and questions into one local workflow. I defined how it should organise my notes and which material can be processed or shared.

My contribution

I defined the note workflow, privacy rules and filing areas, then reviewed the implementation built with AI tools.

01

Use the areas I already have

A saved note receives an ID and timestamp. The filing step chooses from my existing areas instead of creating new categories each time.

I can find a note through search or a map of connected notes. Both open the same saved material.

02

Answer with the source attached

The question feature cites the notes used in its answer. A notes-only setting tells it to say when the answer is missing.

If an answer includes general knowledge, that part is labelled separately so I can tell it apart from my saved notes.

03

Decide where the data goes

Personal notes use local processing. If that route is unavailable, they wait rather than being sent to a cloud model.

A public export includes only approved, shareable notes. The private collection and working files remain separate.

04

Current state

Capture, organisation, the map and questions are built locally. The public export is also built, but remains unpublished.

A public demonstration would use invented notes to show the workflow and its source citations.
