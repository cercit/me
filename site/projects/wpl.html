This project connects WPL scorecards with squad and auction data. The aim is to make questions about spending and performance possible using tables that can be joined consistently.

My contribution

I defined analysis questions and reviewed the dataset structure and source matching. AI tools helped with processing and notebook development.

01

Connect the records

The local package has eight data tables and a dictionary. Match IDs connect deliveries and scorecards; season, team and player identifiers connect those records to squads.

The documented scope covers the 2023–2026 seasons. Processing scripts, a notebook and an insights workbook are saved locally.

02

Match names across sources

A player can appear under an abbreviated scorecard name and a full auction name. The dataset uses stable IDs where available and reviewed aliases for the other cases.

The Bangalore-to-Bengaluru team rename is normalised so the franchise stays together in comparisons.

03

Explain the blanks

An unsold player has no sale price. An unpublished fee is also blank, for a different reason. Those cases are documented instead of being filled with an invented average.

The documentation also explains squad members who did not play and describes checks reconciling runs and wickets with the match data.

04

Presenting the analysis

The current work is a local dataset and analysis package. A useful portfolio addition would be a short set of charts answering one question, with the joins and sample sizes beside the findings.

For example, squad spend can be compared with season points. The result still needs to account for the small number of teams and seasons.
